      Methods & sources.

      Data is fetched on the server once an hour by a scheduled job, cached, and served as a static file — the page never calls the Taskmarket API from your browser. Money is shown in OUSD; the API reports integer micro-OUSD (1 OUSD = 1,000,000), so every money figure is the API value divided by 1,000,000. Distinct posters per week are computed from the /api/tasks list (the requester field, grouped by ISO week, last 8 weeks). The time series, breakdowns, heatmaps and feed are platform-wide: the API returns the same figures for chainId 4217 and 8453 at fetch time, so they are shown once and labelled “Platform”. Market stats and the task list are chain-specific and change with the chain switch.

      Endpoints used:

        Refresh: hourly (scheduled job, scripts/fetch-data.mjs), data file cached for at least 60 seconds. No wallet connection. No analytics or tracking that collects personal data. No names are attached to wallet addresses — addresses are shown truncated, as the API returns them.

        Made for a paid Taskmarket bounty (TSK-BRK611AN). Not an official Taskmarket product.
